# CLAUDE.md — Spelling Time (project context for Claude Code)

## Goal
Static games site for Jason's Grade-3 daughter: spelling (weekly `words.txt`), math, coding, fun, and a garden reward. Hosted on GitHub Pages at his domain. Targets: iPad (Safari) + touch Chromebook. **She discourages easily**: no visible scores/timers/streaks/"wrong"/lives; progress is hidden (parent panel only); rewards are positive-only.

## User prefs (Jason)
Java dev + cybersecurity background, learning Python (prefer Python for tooling). macOS primary, **MacPorts not Homebrew**. Power user, AI novice (suggest prompting/context tips). Wants concise answers, inline source URLs, no sycophancy, explicit uncertainty.

## Hard constraints
- Plain HTML/CSS/vanilla JS ES modules. **No build, no deps, no server, no framework.** Keep it that way.
- Weekly workflow = edit `words.txt` -> `git commit/push`. Don't add steps to it.
- `speechSynthesis`/`Audio.play()` must run synchronously inside the tap (iOS). Games speak at round start from the tap that began the round; `open()` in `js/app.js` mounts synchronously.
- On-screen keyboard (avoids iPad autocorrect) + physical keys. Touch targets >= ~44px.
- Spellbound (github.com/benSlaughter/spellbound, MIT per README, no LICENSE file) is a mechanics reference only; games were rewritten, no code copied.

- Word Search board (issue #51): `WORDS` 6 words, side `max(MIN 8, longest word)` up to `MAX` 12 (was 8 words, 10-14), so letters are bigger (8x8 measured: 42 px at 390x760, 55 px at 1180x740 iPad landscape, 67 px at 820x1100; was 33/43/53 px at 10x10); words longer than 12 are left out. 8 fixture words fit 8x8 in 100% of 2000 trials (overlaps allowed).
- Word Search touch (issue #51): one pointer at a time (`pointerId` + capture; a palm/second finger is ignored). Cells come from geometry (`gridPos()` measured from the corner cells; gaps aren't dead zones), not `elementFromPoint`. Drag end = `snapEnd(start, pos, size, prev)` (exported, pure): nearest of 8 directions, length by projection, hysteresis `HYST` 0.25 cell for length and `DIR_HYST` ~8 deg for direction. Release checks the line ON SCREEN (never re-hit-tests the lift point: finger roll-off and gap lifts lost words). Tap = press that never left its letter; a real drag clears a pending tap; sliding back to the first letter cancels; tap-tap off a line restarts from the 2nd tap. `evaluate` accepts the exact string (either way) or a remaining placement inside the selection with <= `SLACK` (1) extra letters, colouring only the word's cells. A miss fades the checked letters (`.cell.miss`, no 'wrong').
- Baffle: 5x5, `generate(words)` (greedy embed + simulated annealing, 8 restarts x 4000 iters, 400 ms budget) maximises how many list words are traceable; `findPath(grid, word, start=[])` (start = required leading cells). Targets = list words on the board; any other `inDictionary` word (3+ letters) = bonus; list words always valid. `award()` per new word. No visible count; slots always shown (`.bf-slots[data-w]`, `.done`, hinted `.now`). 💡 Hint blinks (`.bf-tile.blink`) the next cell of the open target that keeps the most of her path (trims the rest), else first open slot; ties prefer the last hinted word; speaks the word when k=0 or the hinted word changes. Look-ahead `.bf-tile.next` = unused neighbours j with `findPath(grid, w, [...path, j])` for some unfound list word w (list only, no dictionary); `.bf-current.word` = path spells one. - Coding engine (`js/code/`, issue #19): program = JSON array of `{op, arg?, body?}` (`repeat` has `arg` + `body`; `forever` has `body`). `forever` yields a `{tick: true}` item each pass (capped by the normal budget; `threads()` runs with `budget: Infinity`). `walk(program, {maxRepeat=20, budget=500})` generator yields `{block, path, n}` (path = indexes into nested bodies) and returns `'capped'` at a limit; budget counts steps AND repeat passes, so repeat 99 of repeat 99 (even empty) stops fast. `runner({program, exec, onStart, onActive, onEnd})`: `play()` from the start, `step()` one at a time (continues the current run), `stop()` -> onEnd('stopped'), `reset()` (program edited; no onEnd). exec returns a truthy reason to end the run ('goal'/'bonk'); onEnd also gets 'end'/'capped'. Op metadata `{icon, word, say, color, iconClass?, swatch?}`, word/say/swatch may be fn(block). Drag to reorder: pass `onMove(parentPath, from, to)` (+ `canDrag()`, false while running); pointerdown on a chip, becomes a drag after `DRAG_PX` (10 px), ghost `.code-ghost` (position fixed) + drop bar `.code-drop`, nearest sibling decides before/after; siblings = same container only (a box header drags the whole box; no moves into/out of boxes yet). The click ending a drag is skipped by a `dragged` flag that the next pointerdown clears (a time window swallowed quick taps). `.can-drag .code-chip { touch-action: none }` (touching a chip doesn't scroll). - Offline + updates (issue #13; design, measured GitHub Pages headers and the consistency discussion in the issue comments). `sw.js` scope `/pes3/`: cache-first from the newest complete generation `pes3-c1-<ms>` (has `__complete__`); misses are cached and trigger `verifySoon()` (full check 3 s later); byte-range requests answered from cache (Safari audio). Every stored/served response gets `Cache-Control: no-cache` (`keep()`): with Pages' `max-age=600`, Chrome reused fresh in-memory modules on reload and skipped the worker. Page (`js/offline.js`, called from `app.js` after the menu): register, `warm` (performance resource entries + dict + recordings + icons + logo), full `check` on launch, probe on `visibilitychange` and every `home()`; a probe becomes full if the last full check (localStorage `spelling-games.offline.fullcheck`) is > 6 h old; window `error`/`unhandledrejection` -> full check (max 1 per 5 min). Probe = GET `words.txt` (bytes) + HEAD `js/app.js` (ETag vs its own stored ETag; non-`"hex-hex"` -> full). Full round = HEAD app.js (before), per file: text GET + byte compare, `BIG` (`/dict/`, `.m4a`, `.png`) HEAD + size suffix then GET + byte compare if moved; HEAD app.js (after). **Invariant: a generation is used only if all non-BIG files' ETag times are within `WINDOW` (20 s) = one deploy** (`consistent()`; if ETags aren't `hex-hex`, fallback = app.js ETag same before/after the round). Mixed -> no swap, no in-place writes, retry after 3 s and 6 s, then keep the current copy (`result: 'mixed'`). Consistent + no changes -> fresh responses stored in place (new ETags). Changes -> new generation, `promote()`, `broadcast()` `{type:'updated'}` to all windows. `check()` returns `{updated, result, error?}` with result quiet|same|swapped|mixed|offline|error: `offline` only when `navigator.onLine === false`, any other failure = `error` with the message + failing URL (`naming()` wraps each fetch/body read; issue #24); `status()` includes `last` (shown in the parent panel: "no internet" vs "couldn’t finish (<error>)"). A failed check never changes the copy in use; `saveFull()` counts only same/swapped/mixed. Update applies via `location.reload()` only when not busy (`inGame` or `.overlay`); else `reloadIfPending()` in `home()`.
