# 🟩 Wordal

**The goal:** Figure out the secret word in six tries.

## How to play
1. **Listen** to the secret word. Tap 🔊 to hear it again. The boxes show how many letters it has.
2. **Type a guess** with the keyboard. Use ⌫ to erase.
3. Tap **Check ✔**.
4. Each letter changes color:
   - 🟩 **Green** = right letter, right spot!
   - 🟨 **Yellow** = right letter, but in a different spot.
   - ⬜ **Grey** = this letter is not in the word.
5. Use the colors to make a better guess!

## What happens next
- You have **six tries**. Use the clues to get closer each time.
- Spell the word and you win! Tap **Next ➜**.
- If it takes all six, the game shows you the word.

## Tips
- Keep the green letters where they are.
- Move the yellow letters to new spots.
